YouTube Picture-in-Picture

Settings are saved automatically and sync with your Chrome profile.

How automatic PiP works

A page cannot open picture-in-picture on its own without a click. The one exception Chrome offers is the Media Session enterpictureinpicture action: Chrome itself fires that action when you switch away from a tab that is playing media, and this extension registers a handler for it.

According to Chrome's documentation, automatic picture-in-picture for media playback is available from Chrome 134 (rolled out gradually), and a page is only eligible when all of the following are true:

  • The video is in the top frame of the page (not an iframe).
  • The video is playing, has audio focus, and was audible within the last two seconds.
  • The site has registered an enterpictureinpicture media session handler.
  • Your Media Engagement Index for the site is above Chrome's threshold — that is, you watch media on youtube.com often enough — or you have explicitly allowed automatic picture-in-picture for the site.
  • The page's URL is considered safe by Safe Browsing.

Chrome documents that the automatic picture-in-picture window opens unfocused and is closed again by Chrome when the page becomes visible. The "Leave PiP when I come back" option above is a safety net for the cases where that does not happen.

If automatic PiP never triggers

Chrome may show a prompt asking whether youtube.com may enter picture-in-picture automatically (every time, just once, or never). You can also set it yourself. Chrome settings pages cannot be opened from a link, so copy this address into the address bar:

  • chrome://settings/content — then open Additional permissions and choose Automatic picture-in-picture, and allow it for https://www.youtube.com.

You can also reach the same permission from the icon at the left of the address bar while you are on YouTube: Site settings → Automatic picture-in-picture.

Note: the exact wording and grouping of this permission differs between Chrome versions, and very recent Chrome versions can open picture-in-picture automatically on their own for some sites. If automatic PiP still does not happen, the PiP button in the player always works, because a click counts as a user gesture.
